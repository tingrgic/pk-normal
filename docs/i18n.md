# Languages: Croatian, English and German

Every route shares the HR / EN / DE switch at the top. The choice is stored in
`pk-normal-language-v1`. The site starts in Croatian when no valid saved choice
exists. Blocked storage still allows switching for the current visit. Switching
updates existing React components without changing routes or resetting games.

## Implementation

- `src/i18n/catalog.json`: Croatian message keys with reviewed English and German
  equivalents. Proper names, registered teams, addresses and source URLs remain
  unchanged. Translations do not establish new facts or change federation data.
- `src/i18n/translate.ts`: pure translation with named/numbered interpolation,
  whitespace preservation and a Croatian fallback. Interpolation never evaluates
  HTML or recursively translates a user-entered name.
- `src/i18n/Language.tsx`: shared context, accessible switch, persisted preference,
  HTML language and route-specific titles/descriptions. All touch targets are 44px.
- Both SSR and the initial browser render use Croatian to avoid hydration mismatch;
  the saved choice is restored after hydration. No remote translation API, tracking,
  language-based URL routing or browser-language guessing is used. Without
  JavaScript the prerendered Croatian content remains available.

Coverage includes landing sections, menus, accessible names, sponsor links,
all seven counter game modes and rules, live scoring notices, atlas filters,
map controls/fallbacks, calendar files, odds model explanations, results and
confirmation dialogs. Dates and odds use `Intl` with hr-HR/en-GB/de-DE; all
fixture times stay in Europe/Zagreb. Official data dates are not refreshed by
translation. Map place names remain geographical names.

## State and compatibility

Counter rules and score calculations are unchanged. An optional boolean
`generatedName` on a player distinguishes automatic labels (Igrač / Player /
Spieler) from user names. Editing the name clears the flag. Older version-1
saves still load; names without the flag remain untouched because they may be
user-entered. Darts, undo, ordering, saves and ten-player layouts are preserved.

Virtual duel status messages store a message key and values so an already shown
result translates when switching, without drawing a new outcome or changing
points/history. The map rebuilds its language-dependent labels with cleanup,
retaining the selected match and 2D/3D choice. Downloaded ICS descriptions follow
the selected language while UIDs, official teams, UTC starts and sources stay
identical; UTF-8 folding is preserved.

## Verification

`tests/i18n.spec.ts` verifies catalogue interpolation, calendar output, all routes,
metadata, refresh, keyboard-accessible toggle state, custom player names, active
scores, saved games, simulated results, blocked storage, both translations at
all nine viewports, and mobile accessibility. Existing full regression tests
continue to cover the Croatian baseline. `scripts/i18n-qa.mjs` scans rendered
text/accessible attributes for untranslated catalogue entries, checks overflow,
and captures English/German desktop and phone screenshots in `docs/qa/`.

When adding content, add both translations and render through `t`. For dynamic
sentences, prefer a single interpolated message so languages can reorder words.
Keep engine data language-independent and translate only at the UI boundary.
